# Wikitext test fixtures

These files are the raw wikitext of English Wikipedia articles, used by
`SweblePlainTextTest` to compare plain-text extraction on real-world markup.
They are test resources only and are not included in the built plugin jar.

The article text is by Wikipedia contributors and is licensed under the
[Creative Commons Attribution-ShareAlike 4.0 International License](https://creativecommons.org/licenses/by-sa/4.0/)
(CC BY-SA 4.0), not under this project's Apache License 2.0. The files are
unmodified copies of the revisions listed below, downloaded on 2026-09-26.

| File | Article | Revision |
|---|---|---|
| `Apache_Lucene.txt` | [Apache Lucene](https://en.wikipedia.org/wiki/Apache_Lucene) | [1369045978](https://en.wikipedia.org/w/index.php?oldid=1369045978) (2026-08-12) |
| `Germany.txt` | [Germany](https://en.wikipedia.org/wiki/Germany) | [1376744286](https://en.wikipedia.org/w/index.php?oldid=1376744286) (2026-09-26) |
| `Albert_Einstein.txt` | [Albert Einstein](https://en.wikipedia.org/wiki/Albert_Einstein) | [1376862306](https://en.wikipedia.org/w/index.php?oldid=1376862306) (2026-09-26) |

The contributors to each article are listed in its revision history
(`https://en.wikipedia.org/w/index.php?title=<Article>&action=history`).
To refresh a fixture, download a revision with
`https://en.wikipedia.org/w/index.php?oldid=<revision>&action=raw` and update the table.
